# India Economic Intelligence Dashboard

## Project Overview
An economic data analytics project exploring India's
inflation patterns and RBI monetary policy rates using Python.

## Objectives
- Analyze historical RBI repo-rate changes.
- Compare inflation across CPI categories.
- Identify categories with the highest and lowest inflation.
- Prepare datasets for visualization in Power BI.

## Tools Used
- Python
- Pandas
- Matplotlib
- Excel
- Power BI

## Datasets
- RBI monetary policy rates
- MoSPI Consumer Price Index (CPI) category data

## Key Findings
- The repo rate ranged from 4.0% to 9.0% in the
  available observations.
- The latest recorded repo rate in the dataset was 5.5%
  on 7 October 2026.
- CPI inflation varied across categories in the August 2026 data.

## Project Status
Data cleaning and initial exploratory analysis completed.
Further analysis and dashboard development are planned.
